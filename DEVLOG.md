# Devlog

## Wpis 4
Kardzde pudełko w css zawiera margines, ramkę, padding, i zawartość, każdy z tych elementów można edytować przy pomocy kodu.
Do obiektów w html dodajemy klasy tak by móc sprecyzować element do edycji przy pomocy css.
Istnieją 2 popularne typy układy typu pudełek: flex do stylizacji w jednej osi i grid do stylizacji wierszy i kolumn.
Trudnością stylizacji pudełek jest brak wyświetlanych błędów, oraz część opcji nie zmienia elementu
